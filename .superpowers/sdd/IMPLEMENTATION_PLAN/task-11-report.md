## Implemented contracts

Exports are server-derived projections of immutable notebook history intersected with current snapshot grants and content availability. JSON preserves typed original protocol, forms, versions, evidence, proposals, decisions, artifacts and external-note provenance; Markdown renders readable histories and references; study/result CSV includes review, unit/context and original evidence. CSV text neutralizes formula prefixes while typed numeric values remain numeric. Excel mode adds UTF-8 BOM. Revoked inputs remove dependent derived records as a whole and leave minimal omission markers. Operational provider credentials, MCP credential hashes/files, executable settings, jobs and active approval authority are excluded. Original document page parts are retained for exact evidence validation. Cached exports and chunk reads recheck current authorization and document availability.

Preview reports format, exact serialized size, record counts, sensitivity, missing bibliography metadata and optional PDF byte totals. Create is idempotent; artifact IDs mediate bounded 24,000-byte transfers. The privileged bridge owns the native FilePicker, verifies SHA256 before and after saving, checks cancellation/current scope and returns a filename/size/hash receipt without renderer paths. The generated ExportCommand schema and actual EngineController route allowlist admit only the explicit operations; HTTP and renderer caps are unchanged.

Bibliography uses the installed Zotero translator contract inspected in `task-11-native-reference-preparation.md`: BibTeX, RIS and CSL-JSON have fixed verified translator IDs. Explicit server-authorized compound parents are revalidated through SourceBridge's serialized notifier barrier. A metadata allowlist is applied before native field reads; abstractNote, extra, notes, attachments, unbounded clone and load-all operations are excluded. Translators receive isolated metadata-only items. The native itemDone callback attaches genuine source IDs/URIs, without invented citekeys or BBT. A dedicated scoped bibliography-access route and SQL metadata projection avoid collecting research/text merely to export a bibliography. Native translation remains a pending acceptance boundary.

Backup ZIP defaults to no PDFs. Optional PDFs are authorized and hashed before preview, then copied only from the frozen authorized list. Import reads bounded entries without filesystem extraction: rejects traversal, absolute/non-allowlisted paths, duplicates, symlinks, excess expansion/count/size, hash/version/schema mismatches and unresolved or altered nested evidence. Archives never execute content or restore active jobs, connections, grants, local approvals or automatic Zotero writes.

Import requires explicit confirmed one-to-one profile/library/parent/content mappings to currently granted destination identities. Staging chunks respect the unchanged HTTP limit. Original values, immutable form/protocol versions and external-client provenance stay in imported history, distinct from current local decisions. A bounded import chain and origin-group identity preserve transitive copies without conflating generations. Imported evidence reference creation requires exact indexed original text and mappings; wrong/unmapped evidence fails. Imported PDF presence alone grants no reader access. Current visibility is checked before history inspection and cached export replay; revocation of one imported subset does not suppress unrelated permitted history.

The Sources view integrates export/import controls with PT-BR/en-US catalogs, explicit preview/create/save buttons, bounded source/history pagination and staged source/content mapping. Renderer commands use getRandomValues keys, stable uncertain-outcome retries and confirmed invalidation. Typed imported decision/form/protocol/proposal/evidence rendering retains original numeric forms and units, with literal inert rendering for other record types. Imported values never become local approval controls. Existing focus/theme classes and keyboard/IME/busy conventions are reused.

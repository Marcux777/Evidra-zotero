## Implemented contracts

Migrations009–011 add immutable protocol versions, append-only human screening events, exact research preparations/runs/artifact versions, concrete note previews and approved-write outbox. Migration008 remains unchanged. Protocols bind criterion IDs, inclusion/exclusion kind, title/abstract or full-text applicability and an immutable extraction form version. Local reviewer labels have separate expected revisions. Conflicting latest reviewer decisions and observed event counts are reported; unavailable historical search counts remain null. AI screening artifacts never write human screening decisions. An absent abstract or full text cannot justify an EXCLUDE model output.

ResearchService implements SCREENING, SYNTHESIS and AUDIT through the existing ProviderRegistry.generate admission, call identity, reservation, SENT, usage and cancellation boundary. It shares exclusion with extraction jobs and active conversations. Preparation performs no model call and freezes the requested settings, protocol, profile, effective system/prompt/schema, evidence, coverage and provenance. ResearchPreview.request preserves context/output budgets and Ollama options for exact inspection after restart. Input estimates explicitly use UTF-8 bytes plus overhead; they are not represented as a verified paid-call InputBound. No alternate provider request, hidden retry, download or remote tool execution was added.

Every content-bearing read and commit reauthorizes current source grants and original evidence against the immutable snapshot. Model and native I/O run outside SQLite transactions. A validated output checkpoints separately before the guarded artifact/complete transaction. Actual child-process interruption after SENT blocks resend; interruption after a validated checkpoint can finish that checkpoint on explicit resume without another model call. Confirmed usage with invalid output produces FAILED with its causal reason; genuinely uncertain sends retain BILLING_UNKNOWN. Cancellation/revocation cannot commit streamed partial output. Status reads and cancellation remain available when document revalidation fails. Task-owned completed worker entries are removed.

Synthesis consumes all matrix pages, retaining approved/corrected human cell values and their original evidence rather than replacing them with later competing proposals. Explicit opt-in includes unreviewed proposals with UNREVIEWED/MIXED provenance labels. Prepared input caps fail explicitly: at most30000 cells,450000 prompt characters and850000 serialized preview characters. Screening/audit evidence selection is bounded to40 chunks with candidate counts and partial coverage. Missing/unindexed studies remain explicit. Generated sections retain cell/evidence references, contextual comparability statements and limitations; the validator rejects promotion of unreviewed inputs into reviewed provenance. Semantic accuracy and comparability remain human review matters.

Audit preserves literal spans in the pasted text, validates non-overlap and prepared evidence IDs, and distinguishes anchor validation from four proposed support states. DIRECT references require supplied evidence from the named source; INDIRECT_MENTION and NOT_IN_NOTEBOOK cannot be presented as directly read papers. Notebook title/DOI matches cannot be relabeled as absent references. Human approve/correct/reject creates immutable artifact versions with structured output controls; model output remains an AI proposal with a separate human review state.

Note creation requires a concrete preview bound to one artifact version, destination compound identity, canonical HTML hash and independent UUID, followed by explicit human approval. Preview HTML is escaped, bounded to48000 UTF-8 bytes and wrapped in the installed Zotero note container. Native NoteBridge is shared across windows and serializes publication. It revalidates current scoped source, regular parent, library identity and current editable user/group library before creation. The renderer cannot submit raw native HTML, a begin/ack command or a fabricated native item ID.

Outbox begin grants creation once. All later attempts must reconcile the UUID; an uncertain begin with no match stops for review. Native reconciliation searches only the target library's notes, including deleted items, using both the exact own UUID tag and UUID text, with bounded candidate sets. It also checks an already saved note key. Trashed, modified, moved or ambiguous matches fail explicitly. New notes receive the exact `evidra:ai` tag, `data-evidra-origin="ai"` marker and separate `evidra:outbox:<uuid>` tag/HTML UUID. Normal Zotero.Item.saveTx is used. The normal SourceBridge epoch barrier is preserved; a post-save SCOPE_STALE triggers independent current revalidation and UUID readback before acknowledgement, never silent success or another creation. Readback verifies HTML hash, provenance markers, tags, library, parent and note key. Original notes are never edited/deleted and native undo coverage is not claimed.

Installed `omni.ja` was inspected read-only to verify the note wrapper and normal save API. `.local/task09/installed-note-format.json` records bounded source excerpts and hashes; this is API inspection, not a native write test. The controller's profile, model service and ignored native helpers were not operated or changed by this worker.

# Zotero target API reference

Target inspected: Zotero 10.0.1 / Firefox 140 ESR, 2026-09-05. This is a source reference, not a claim that the Evidra integration has passed native smoke.

| Boundary | Target API | Source and implementation constraint |
|---|---|---|
| Bootstrap | install/startup/onMainWindowLoad/onMainWindowUnload/shutdown/uninstall | [Official sample](https://raw.githubusercontent.com/zotero/make-it-red/master/src-2.0/bootstrap.js). Remove window listeners/UI and owned processes on unload. |
| Menus | Zotero.MenuManager.registerMenu / unregisterMenu | [Target source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/pluginAPI/menuManager.js). Use menuID/pluginID/target/menus and plural context.collectionTreeRows. |
| Workspace | Native DOM dialog/panel in Zotero main window | [Target tabs source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/tabs.js). Do not use an unknown Zotero_Tabs.add type: getState persists it, restoreState requires a defined hook and can fail after removal. ADR 0002 selects a panel and leaves host session methods untouched. |
| Reader-adjacent panel | Zotero.ItemPaneManager.registerSection | [Target source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/pluginAPI/itemPaneManager.js). paneID/pluginID/header/sidenav/bodyXHTML and lifecycle/render hooks; do not invent a separate reader sidebar API. |
| Selection | getCollectionTreeRows/getSelectedLibraryIDs/getSelectedCollections/getSelectedSavedSearches | [Zotero 10 changes](https://www.zotero.org/support/dev/zotero_10_for_developers). Singular selection getters throw; mixed collections/searches/libraries allowed. |
| Item list | getSelectedItems/getSortedItems; row.isObjectRow for manual walking | [Target view](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/collectionViewItemTree.jsx). Skip library headers/spacers. |
| Saved search | Zotero.Search / search results; item.parentID/parentKey | [Search source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/data/search.js). Child results need parent normalization while retaining selected content permission. |
| Library permission | Zotero.Libraries.get(libraryID).editable / filesEditable; item.isEditable | [Library source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/data/library.js). Local IDs do not stand for remote group IDs. |
| File resolution | await attachment.getFilePathAsync() | [Item source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/data/item.js). Returns path or false; engine independently revalidates regular file/reparse/hash/identity. |
| Page navigation | Zotero.Reader.open(attachmentID, {pageIndex}); reader.navigate(location) | [Reader source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/reader.js). Physical pageIndex is zero-based; page labels are separate. |
| Annotations | attachment.getAnnotations; Zotero.Annotations.toJSON | [Annotation source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/annotations.js). Preserve text/comment/position/type and human provenance. |
| Approved note | new Zotero.Item('note'), setNote, saveTx, Zotero.Items.getAsync | [Native tests](https://raw.githubusercontent.com/zotero/zotero/10.0.1/test/tests/itemTest.js). Permission, preview, outbox UUID, reconcile and readback precede acknowledging note creation; creation is not undoable. |
| Change signals | Zotero.Notifier.registerObserver/unregisterObserver | [Notifier source](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/notifier.js). Register item/collection/search/group/tab interests and remove observer on shutdown. |
| Bibliography | new Zotero.Translate.Export; setItems/getTranslators/setTranslator/setLocation/translate | [Native export wrapper](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/fileInterface.js). Use only selected permitted item objects; no mandatory Better BibTeX. |
| Owned helper | Mozilla Subprocess.call/wait/kill | [Subprocess docs](https://firefox-source-docs.mozilla.org/toolkit/modules/subprocess/toolkit_modules/subprocess/index.html). Arrays of arguments, no shell, pipe logs without secrets, kill only owned child if necessary. |
| Privileged local I/O | IOUtils.readJSON/writeJSON/writeUTF8/stat/remove/makeDirectory | [IOUtils docs](https://firefox-source-docs.mozilla.org/dom/ioutils_migration.html). Atomic temp file doesn't establish Windows DACL security by itself. |

Operational policy remains separate: the agent may use only the personal local Zotero helper for actual Zotero operations, with no UI automation or personal-library mutation. That helper currently supports base-URL/executable environment overrides but not a profile-selecting startup argument. Native test-profile launch/installation must not silently bypass that boundary.

## Test-profile isolation reference

The target [dataDirectory.js](https://raw.githubusercontent.com/zotero/zotero/10.0.1/chrome/content/zotero/xpcom/dataDirectory.js) handles an explicit `-datadir` before preference/default discovery (lines 55–78); it accepts an absolute path with an existing parent, or `profile`. A profile alone is insufficient isolation: the ordinary default-discovery branch inspects other profiles and the default data directory. The test launcher therefore must supply both an isolated profile and an explicit disposable data directory, then verify the running profile/data paths before any fixture write. This is a source-derived harness requirement, not evidence of an executed isolated launch. The [official multiple-profile guide](https://www.zotero.org/support/kb/multiple_profiles) also documents that automatic separate-data-directory behavior has not always occurred.

Two ancillary raw-source lookups for `defaults/preferences/prefs.js` and `app/assets/app.ini` returned tool Internal Error on 2026-09-05. They supplied no evidence; no startup or preference operation was attempted from them.
